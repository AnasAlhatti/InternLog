---
name: GitHub access after handoff
description: Distinguishing saved GitHub authorization, usable project access, and local versus remote commits.
---

Verify usable GitHub access before claiming that a repository exists or that commits have been uploaded. Neither a configured remote nor healthy authorization metadata guarantees working credentials. Local milestone commits are not a remote backup.

**Why:** After the conversation moved into this project, GitHub authorization metadata reported a healthy account, but the connection exposed no usable access and the connection dialog could not open.

**How to apply:** Preserve local history when connection setup is blocked, state clearly which remote work is pending, and do not treat authorization metadata as evidence that a GitHub write succeeded.
