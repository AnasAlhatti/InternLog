Build a complete, responsive web app called “InternLog” for interns to track their daily work and generate weekly progress reports.

Project goal:
Make it easy for an intern to answer:
- What did I work on?
- What did I learn?
- What is blocking me?
- What should I do next?
- What can I share with my supervisor this week?

Use React, TypeScript, and Tailwind CSS. Keep the first version simple and runnable in Replit. Store data in localStorage so users can use it immediately without creating an account or setting up a database.

MAIN FEATURES

1. Dashboard
Show:
- A friendly welcome message.
- Total entries.
- Total hours logged.
- Number of unique skills recorded.
- Number of unresolved blockers.
- Recent daily entries.
- A prominent “Add Entry” button.

Include an empty state explaining how to add the first entry.

2. Daily progress entries
Users must be able to create, edit, and delete entries.

Each entry should contain:
- Date, defaulting to today.
- Short title.
- Tasks completed.
- What I learned.
- Blockers or challenges, optional.
- Blocker status: open or resolved, when a blocker exists.
- Next steps.
- Hours worked.
- Skills used, entered as tags such as React, Python, Git, or teamwork.

Require a date, title, and completed tasks.
Allow hours between 0 and 24.
Confirm before deleting an entry.

3. Entry history
Show entries newest first in readable cards.

Each card should show the date, title, hours, skills, and a short task preview. Clicking a card should reveal the full entry.

Support:
- Text search across titles, tasks, and learning notes.
- Filtering by date range.
- Filtering by skill.
- Filtering for unresolved blockers.
- Clear filters.

4. Weekly report
Let the user select a week running Monday through Sunday.

Generate a structured report from that week’s entries with:
- Week dates.
- Total hours.
- Completed work, grouped by day.
- Lessons learned and skills practiced.
- Open blockers.
- Recorded next steps.

For the initial version, generate this report directly from the saved entries. Do not invent achievements or label this feature as AI-powered.

Provide:
- An editable report preview.
- Copy to clipboard.
- Download as a Markdown file.

If there are no entries for the selected week, show a helpful message.

5. Settings and data management
Allow the user to save:
- Their name.
- Internship role.
- Organization name.

Provide:
- Export all app data as JSON.
- Import a previously exported JSON backup.
- Validate imported data before changing existing data.
- Confirm before replacing existing data.
- Clear all data with confirmation.

Explain that entries are stored in the current browser and that exporting a backup is recommended.

DESIGN

Create a polished, friendly dashboard with:
- A light background and indigo accent color.
- Clear typography, rounded cards, and subtle shadows.
- Desktop sidebar navigation.
- Simple mobile navigation.
- Accessible labels, visible keyboard focus, and good contrast.
- Useful empty states and success/error messages.

Navigation:
- Dashboard
- Entries
- Weekly Report
- Settings

Include a “Load Sample Data” action for demonstrations. Sample data should contain five realistic internship entries, including one open blocker and one resolved blocker. Do not load sample data automatically or overwrite existing entries without confirmation.

IMPLEMENTATION REQUIREMENTS

- Make all buttons and features functional.
- Keep components and storage utilities organized.
- Handle missing or invalid browser data gracefully.
- Treat entry dates as local calendar dates.
- Show a clear error if saving fails.
- Avoid adding authentication, external integrations, or paid services.
- Include a README explaining setup, features, limitations, and demo steps.
- Add an MIT license and a short CONTRIBUTING.md file for sharing as an open-source project.

Before finishing, check:
- Creating, editing, and deleting entries.
- Data persisting after refresh.
- Search and filters.
- Weekly report date boundaries and totals.
- JSON export and import.
- Mobile layout.

Finish with a working preview and a brief explanation of how to use the app.
